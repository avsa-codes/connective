
# Connective

Connective is a platform that helps businesses manage and improve their digital presence.

## Monorepo Structure

- `apps/api` — Backend API
- `apps/mobile` — Merchant mobile application
- `apps/websites` — Public merchant website engine
- `packages/contracts` — Shared schemas and API contracts

## Technology Stack

- Node.js, Express, TypeScript
- React Native, Expo, TypeScript
- Next.js, React, TypeScript
- PostgreSQL, Prisma

## Development Status

Project foundation and database setup are in progress.
